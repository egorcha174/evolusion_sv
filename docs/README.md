## 🚀 БЫСТРЫЙ СТАРТ (3 шага)

### 1. Скопируй код из quick_start.md
```
src/lib/types/camera.ts
src/lib/components/CameraCard.svelte
src/lib/components/CameraCardPreview.svelte
src/lib/components/CameraCardLive.svelte
```

### 2. Адаптируй конфигурацию
```typescript
const camera = {
  name: 'Твоя камера',
  source: 'имя_в_go2rtc', // например 'frontdoor_call'
  mode: 'live', // или 'preview'
  go2rtcHost: 'localhost:1984', // твой адрес go2rtc
  go2rtcProtocol: 'http'
};
```

### 3. Запусти и проверь
```bash
npm run dev
# Открой http://localhost:5173
# Видео должно показаться
```

## 💡 КЛЮЧЕВЫЕ МОМЕНТЫ

### 1. SSR = Сервер-сторонний рендеринг
- Весь код с `window`, `navigator`, WebRTC → только в `onMount`

### 2. srcObject требует Action
- Svelte не умеет биндить JS свойства
- Нужна custom action для MediaStream

### 3. Очистка ресурсов = важно
- Каждый `onMount` возвращает cleanup функцию
- Иначе утечки памяти

### 4. Архитектура = 4 компонента
- Не комбинируй, не переименовывай
